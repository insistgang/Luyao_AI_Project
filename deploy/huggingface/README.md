# 路遥 Luyao AI

情感陪伴 AI 的 Hugging Face Docker Space，由 GitHub Actions 自动同步。

运行时需要以下 Space Secrets：

- `MINIMAX_API_KEY`
- `LUYAO_ACCESS_PASSWORD`

可选配置包括 `LUYAO_ACCESS_USER`、`MINIMAX_CHAT_MODEL`、`MINIMAX_VOICE_ID`、`MINIMAX_SPEECH_MODEL` 与 `MINIMAX_WHISPER_MODEL`。
